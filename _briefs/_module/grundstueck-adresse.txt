МОДУЛЬ: УЧАСТОК ПО АДРЕСУ (переиспользуемый)
=============================================
Первый раз строится в richtfest/ (Grundstücks-Check). Потом копируется в gartenjahr/ (Gartenplaner) и в будущие демо (Zaun, Pflaster, Dach, PV и т.п.).

Что делает: адрес → контур кадастрового участка + существующие здания → редактируемый план в метрах.

Данные (проверено 06.11.2026)
- Геокодер: Photon (photon.komoot.io, OSM, ODbL) или Nominatim (≤1 запрос/с, без автодополнения).
- Участки и здания: LGLN OpenData, CC BY 4.0, WFS https://opendata.lgln.niedersachsen.de/doorman/noauth/alkis_wfs_einfach
  слои ave:Flurstueck (контур, flaeche, lagebeztxt, gemarkung) и ave:GebaeudeBauwerk (контуры зданий).
  CORS: Access-Control-Allow-Origin * → запрос прямо из браузера. Формат только GML 3.2 (DOMParser). Координаты EPSG:25832 (метры).
  Пример запроса: ?SERVICE=WFS&VERSION=2.0.0&REQUEST=GetFeature&TYPENAMES=ave:Flurstueck&COUNT=10&BBOX=<lat1>,<lon1>,<lat2>,<lon2>,urn:ogc:def:crs:EPSG::4326
- Только Niedersachsen. Для других земель есть похожие открытые WFS (NRW, Berlin, Hamburg и др.), но не делаем, пока нет клиента.
- Рельеф при необходимости: LGLN DGM1 (цифровая модель рельефа 1 м), тоже OpenData — не в первой версии.

Интерфейс (одинаковый во всех демо, стиль — под проект)
- Поиск адреса только по явному действию пользователя (DSGVO: адрес уходит третьим сторонам), раздел в Datenschutz, CSP connect-src на эти домены.
- План сверху: контур участка, здания серым, размеры сторон, площадь. Правка вершин пальцем (GSAP Draggable), сброс.
- Выбор соседнего участка тапом, объединение двух участков.
- Без адреса: ручной ввод ширина × глубина. Кнопка «Beispielgrundstück» для показа на iPad.
- Состояние в sessionStorage; в URL — только геометрия, без адреса.
- Подпись источника: «Quelle: LGLN, Liegenschaftskataster, CC BY 4.0».

Для gartenjahr (дополнение к брифу 05)
- Вход в Gartenplaner: «Ihren Garten laden» (загрузить ваш сад) → участок минус дом = площадь сада; сетка планировщика строится по реальному контуру, а не по klein/mittel/groß. Ручной режим остаётся.
- Песочница с физикой воды/песка не нужна: тяжело для телефона и не помогает заказу. Максимум: поднять/опустить грунт по клеткам (Hügel, Mulde — холм, впадина) и пруд, который «заполняется» до уровня. Делать только если основное уже идеально.
