ПРИЁМЫ ДЛЯ ДЕМО: ИСТОЧНИКИ И ОТФИЛЬТРОВАННЫЕ НАХОДКИ
(обновлять по мере поисков; перед концептом нового демо читать вместе с ПОДХОД_уникальные_демо.txt)

Фильтр: берём идею, а не код. Пишем сами на чистом JS/CSS (Astro, без внешних запросов, DSGVO). Приём проходит, если
1) работает пальцем на телефоне, 2) помогает продать или понять продукт (не просто «красиво»),
3) подходит нише, 4) не тормозит на телефоне, 5) есть вариант для prefers-reduced-motion.
Лицензию кода-образца проверять, если копируем структуру (чаще достаточно идеи).

ИСТОЧНИКИ
- designbookmark.com: каталог ~2800 инструментов, ~95 % шум (AI-агенты, маркетинг, Mac-приложения). Полезна только вкладка «Motion» (anims по компонентам) /motion; там ссылки на Kokonut UI (kokonutui.com) и SmoothUI (smoothui.dev): React-компоненты, у нас берём идеи.
- refero.design: библиотека скринов UI/UX (веб и iOS) для разведки ниши. Что внутри бесплатно, не проверено.
- tympanus.net/codrops: разборы «как сделан сайт» и приёмы (прокрутка, типографика, карусели, WebGL). Лучший источник именно приёмов, а не готовых блоков.
- Не проверено, кандидаты на следующий заход: awwwards.com, godly.website, land-book.com, siteinspire.com, 21st.dev, magicui.design, ui.aceternity.com.

НАХОДКИ С designbookmark/motion (отобрано из ~65)
Подходят часовому/премиум-сайту и конфигуратору:
- Detent dial (kokonutui.com/docs/inputs/detent-dial): диск с «щелчками». Идея: выбор размера запястья или режим подсветки; вибрация на щелчок.
- Slide to confirm (kokonutui.com/docs/buttons/slide-to-confirm): «смахнуть для отправки». Для финальной кнопки заявки, на телефоне естественнее клика.
- Hold button (kokonutui.com/docs/buttons/hold-button): удержание для подтверждения; у нас идея заводной головки уже была, можно вернуть для «Platz anfragen».
- Weight wave: волна толщины переменного шрифта; у нас Archivo variable (ось wght), можно в шапке героя.
- Roll links: перекат текста на ссылках меню.
- Bottom bar: нижняя навигация на телефоне (большой палец достаёт). Годится для сайтов, где меню важнее логотипа.
- Morph popover / Morph island: плашка растёт из кнопки (итог конфигуратора в нижней панели).
- Wheel picker: барабан выбора (даты визита, размера).
- Step progress: шаги заявки, если форма станет длиннее.
- Parallax ticket / Glass lens: наклон карточки и линза (линза у нас уже есть в calenberg и в демо оптики).
Не берём: всё про AI-чаты (prompt box, streaming reply, thinking), OTP, пароль, подпись, музыкальные тумблеры: к нашим нишам не относятся.

ПОЛЬЗА НА БУДУЩЕЕ
Не копировать компоненты 1 в 1: у каждого демо свой язык. Из списка брать механику (щелчки, удержание, смахивание) и перекладывать на тему ниши.
