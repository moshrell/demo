ПРИЁМЫ ДЛЯ ДЕМО: ИСТОЧНИКИ И ОТФИЛЬТРОВАННЫЕ НАХОДКИ
(обновлять по мере поисков; перед концептом нового демо читать вместе с ПОДХОД_уникальные_демо.txt)

Фильтр: берём идею, а не код. Пишем сами на чистом JS/CSS (Astro, без внешних запросов, DSGVO). Приём проходит, если
1) работает пальцем на телефоне, 2) помогает продать или понять продукт (не просто «красиво»),
3) подходит нише, 4) не тормозит на телефоне, 5) есть вариант для prefers-reduced-motion.
Лицензию кода-образца проверять, если копируем структуру (чаще достаточно идеи).

ИСТОЧНИКИ
- designbookmark.com: каталог ~2800 инструментов, ~95 % шум (AI-агенты, маркетинг, Mac-приложения). Полезна только вкладка «Motion» (anims по компонентам) /motion; там ссылки на Kokonut UI (kokonutui.com) и SmoothUI (smoothui.dev): React-компоненты, у нас берём идеи.
- refero.design: библиотека скринов UI/UX (веб и iOS) для разведки ниши. Что внутри бесплатно, не проверено.
- tympanus.net/codrops: разборы «как сделан сайт» и приёмы (прокрутка, типографика, карусели, WebGL). Лучший источник именно приёмов, а не готовых блоков.
- Не проверено, кандидаты на следующий заход: awwwards.com, godly.website, land-book.com, siteinspire.com, 21st.dev, magicui.design, ui.aceternity.com.

НАХОДКИ С designbookmark/motion (отобрано из ~65)
Подходят часовому/премиум-сайту и конфигуратору:
- Detent dial (kokonutui.com/docs/inputs/detent-dial): диск с «щелчками». Идея: выбор размера запястья или режим подсветки; вибрация на щелчок.
- Slide to confirm (kokonutui.com/docs/buttons/slide-to-confirm): «смахнуть для отправки». Для финальной кнопки заявки, на телефоне естественнее клика.
- Hold button (kokonutui.com/docs/buttons/hold-button): удержание для подтверждения; у нас идея заводной головки уже была, можно вернуть для «Platz anfragen».
- Weight wave: волна толщины переменного шрифта; у нас Archivo variable (ось wght), можно в шапке героя.
- Roll links: перекат текста на ссылках меню.
- Bottom bar: нижняя навигация на телефоне (большой палец достаёт). Годится для сайтов, где меню важнее логотипа.
- Morph popover / Morph island: плашка растёт из кнопки (итог конфигуратора в нижней панели).
- Wheel picker: барабан выбора (даты визита, размера).
- Step progress: шаги заявки, если форма станет длиннее.
- Parallax ticket / Glass lens: наклон карточки и линза (линза у нас уже есть в calenberg и в демо оптики).
Не берём: всё про AI-чаты (prompt box, streaming reply, thinking), OTP, пароль, подпись, музыкальные тумблеры: к нашим нишам не относятся.

ПОЛЬЗА НА БУДУЩЕЕ
Не копировать компоненты 1 в 1: у каждого демо свой язык. Из списка брать механику (щелчки, удержание, смахивание) и перекладывать на тему ниши.


=====================================================================
РАЗВЕДКА ПО НИШАМ (18.11.2026, веб-поиск; не только часы/ремесло/оптика)
=====================================================================
Честная оценка источников: подборки "best X websites" (Colorlib, Wix, Zarla,
HubSpot, muffingroup) - это маркетинг конструкторов, в основном шаблоны
Squarespace/Wix. Это ровно "усреднённый" вид, от которого мы уходим. Брать из них
только отдельные наблюдения, не эталон. Inspo/siteinspire/land-book по местному
бизнесу почти пусты (SaaS/dev/fintech/агентства). Для ниш нужны реальные сайты
лучших представителей, смотреть руками (WebFetch) перед каждым концептом.

Наблюдения из найденного (проверено только на уровне описаний, не вживую):
- Парикмахерская (Friseur): у Envy Hair клик по мастеру открывает профиль и цены
  всех его услуг (Team = вход в запись). Зарла: "stylist-finder" (подбор мастера).
  Минус всех шаблонов: каталог цен отдельно от записи.
- Пекарня/кафе (Bäckerei): Fox in the Snow - боковая навигация, контент дышит;
  Blackmarket Bakery - крупный характерный шрифт + фото. Шаблонное: слайдер с
  булками + "Kontakt". Реально нужное: сегодняшний ассортимент и часы открытия.
- Автосервис (Kfz-Werkstatt): сильнейший ход - честные цены заранее (Zarla:
  "upfront pricing attacks the trust deficit"), один главный CTA, фото РАБОТЫ, а
  не стока. Аналитичному покупателю - аналитичная страница (диагностика, список).
- Оптика (Optiker): Moscot - вся марка = 100 лет наследия; Ace & Tate - редакционная
  подача; Warby Parker - примерка (VTO). Для местной оптики: запись на проверку
  зрения + примерка оправ, а не каталог.
- Цветочный (Florist): Wilder Flower Co совмещает свадебную студию и розницу;
  сезонная подача ("что цветёт сейчас"). Свадебные - через презентации по сезонам.
- Столяр/ремесло (Tischler): Hook: галерея без текста = нет SEO и нет заявок;
  Austin Joinery: кнопка "Begin Your Project" (начать проект) прямо на главной.
- Строительная фирма (Bauunternehmen): до/после, страницы услуг, форма запроса;
  у лучших - крупные фото проектов на всю ширину. Шаблонное: "Why choose us" + 3 иконки.
- Адвокат/Kanzlei: >60 % трафика с телефона; нужны: области права по-человечески,
  первый шаг (Erstberatung = первичная консультация), цена/порядок, фото людей.
  Шаблон: весы Фемиды, тёмный синий + золото.

ПРАВИЛА, ОТЛИЧАЮЩИЕ САЙТ ОТ "ИИШНОГО" (рабочая версия, правим по опыту):
1. Реальные фото работы/людей/места + текст рядом, а не иконки и градиенты.
   У нас фото = промпты Gemini: делать кадры "из жизни" (рабочее место, руки, мелочи).
2. Один сильный ход на сайт, остальное тихо. Не "эффект на каждую секцию".
3. Структура из ниши, а не hero -> 3 карточки -> отзывы -> CTA. Порядок блоков = то,
   как решает именно клиент этой ниши (цена? мастер? сроки? наличие?).
4. Конкретика вместо лозунгов: цифры, названия, имена, адреса улиц, часы. Никаких
   "Qualität, Leidenschaft, Vertrauen".
5. Заголовок называет предмет, а не обещание. Без выделенного одного слова курсивом/цветом.
6. Нет одинаковых скруглённых карточек с одной тенью; иерархия размерами и пустотой.
7. Свой язык интерфейса, взятый из предмета (шестерня, приборная панель, чертёж), но
   только если он помогает действию (записаться, посчитать, выбрать).
8. Главное действие всегда в пальце: короткий путь к записи/запросу на телефоне.

ПЛАН ДАЛЬШЕ: перед каждым новым демо - 3-4 живых сайта ниши (WebFetch), короткая
запись "есть / нет / раздражает на телефоне" в брифе; сюда переносить только
повторяющиеся находки.
