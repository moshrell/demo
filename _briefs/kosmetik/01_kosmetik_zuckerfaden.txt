=========================================================
Zuckerfaden — «сахарная нить»: так тянется тёплая сахарная паста при шугаринге. Это главный образ сайта.
Папка: zuckerfaden/ в корне moshrell/demo (на ПК D:\Webdesign\zuckerfaden) · категория портфолио: та, что в kravets-site
для красоты (проверить works.ts; если отдельной нет — friseur) → /vorschau/<категория>/zuckerfaden/
Сначала прочитать CLAUDE.md, _briefs/ПОДХОД_уникальные_демо.txt и _briefs/_module/ПРИЁМЫ_источники_и_находки.txt.
Скиллы: frontend-design и hallmark ДО вёрстки, demo-site-workflow для проекта. Фото: zuckerfaden/PROMPTS.txt (уже лежит).
Статус: собрано (19.11.2026), вторая версия после ревью Степана.

ИЗМЕНЕНИЯ ПОСЛЕ РЕВЬЮ 19.11. (имеют приоритет над разделами ниже)
- Палитра: не пастель. Тёмная «медовая» сцена (#1B110B) для героя, калькулятора, комнаты и футера + чистый белый для чтения.
  Мёд — материал, а не плоский жёлтый: WebGL-шейдер (scripts/honig-gl.ts), прозрачность по толщине, блики, мягкая тень.
- Нижняя панель, пилюля Summe и нити рисуются WebGL-мёдом и сливаются мягким минимумом (никаких «песочных часов» из SVG).
- Герой без фото: слой мёда по верхнему краю, капли тянутся и отрываются (WebGL), при прокрутке тянутся сильнее.
  Фото с руками для героя не нужны (Gemini плохо рисует пальцы).
- Шрифты: A Noto Serif Display + Albert Sans (по умолчанию), B Gilda Display + Manrope, C Bricolage, D Literata.
  Переключатель — видимая демо-полоса над шапкой на всех страницах.
- Фигура: плавные силуэты (Catmull-Rom) с разными пропорциями Damen/Herren, фарфор с объёмом, зоны глазуруются мёдом
  со спекулярным бликом, цена — подписью у зоны. Калькулятор помещается в один экран. Лицо — приближение внутри сцены.
- ПК: отдельная раскладка калькулятора (фигура слева, панель справа), нижняя панель = полное меню.

ГЛАВНАЯ МЕТАФОРА: ЗУКЕРПАСТА (сахарная паста) — тёплая, янтарная, прозрачная, тянется
Метафора живёт в интерфейсе только там, где помогает действию. Три места, не больше:
- Выбранная зона на силуэте «глазируется»: заливка янтарной пастой растекается от точки касания.
- Плашка итога (Summe) выглядит как полоска пасты: янтарное полупрозрачное «стекло» с мягким бликом.
- Подтверждение заявки = Terminkarte (карточка записи, какую дают в кабинете): плотная карточка, рукописная
  по виду дата НЕ рисуется шрифтом-«почерком», а просто аккуратно набрана.
Остальное тихое: пудровый фон, крупная типографика, фото «из жизни» кабинета.
НЕТ: карточек с одинаковыми тенями, иконок в кружках, подписей капсом над заголовками, курсивного слова в заголовке,
стрелок «→» в кнопках, слайдеров/каруселей, параллакса, анимации появления на каждой секции,
«премиум» чёрно-золотого, кремового фона с терракотой, стоковых «спа-камней и орхидей».

ШРИФТЫ: ПЕРЕКЛЮЧАТЕЛЬ ДЛЯ СРАВНЕНИЯ (Степан выбирает с клиенткой)
Все пакеты есть на npm (@fontsource, проверено 19.11.2026), латиница + немецкие умляуты/ß. В репозитории ещё не использовались.
 A  Gloock (заголовки) + Hanken Grotesk (текст)   — по умолчанию. Контрастная тёплая антиква + чистый гротеск. «Дорого».
 B  Young Serif (заголовки) + Rethink Sans (текст) — мягкая округлая антиква, дружелюбно, чуть «домашне».
 C  Bricolage Grotesque (всё, variable: opsz/wdth/wght) — современно, с характером, один шрифт.
 D  Literata (всё, variable opsz) — книжная, лучшая читаемость для 60+, спокойно.
Пакеты: @fontsource/gloock, @fontsource-variable/hanken-grotesk, @fontsource/young-serif, @fontsource-variable/rethink-sans,
@fontsource-variable/bricolage-grotesque, @fontsource-variable/literata.
Важно: у Gloock и Young Serif одно начертание (400) → ими только h1/h2 крупно; h3, кнопки, цены — текстовым шрифтом 600.
Реализация:
- Шрифты через переменные --font-display / --font-text; пара = data-font="a|b|c|d" на <html>.
- Панель «Schriftprobe (nur Demo)» (проба шрифтов, только в демо): на ПК маленькая кнопка «Aa» внизу слева,
  на телефоне пункт в меню-шторке. Четыре строки-радио, в каждой название пары, набранное этой парой.
  Переключение мгновенное, без перезагрузки и без прыжка прокрутки (сохранить scrollY, компенсировать сдвиг).
- Выбор хранится в localStorage (try/catch) и в URL ?schrift=b, чтобы Степан мог отправить клиентке ссылку.
- Пара A грузится сразу (preload только woff2 латиницы). B/C/D подгружаются лениво при первом открытии панели
  (динамический import CSS fontsource), чтобы обычный посетитель не качал 4 семейства.
- Флаг "fontSwitcher": true в site.json; false = панели нет совсем (для финальной версии клиента).
- Шкала: текст 18 px на телефоне (не меньше 17), 19–20 на ПК; межстрочный 1.55 для гротеска, 1.65 для Literata;
  h1 clamp ~2.4–4.2rem; длина строки ≤ 66 знаков; цены tabular-nums.

АНИМАЦИИ (полный список; другого движения нет)
1. Герой, один раз при загрузке: по сахарной нити на фото проходит блик (CSS mask с градиентом, ~1.4 с), потом всё неподвижно.
2. Касание зоны: янтарная заливка растекается из точки касания (SVG radialGradient, r 0→100 %, 250 мс) + navigator.vibrate(8),
   где поддерживается. Повторное касание — заливка «стекает» обратно (150 мс).
3. Summe: цифры меняются с коротким перекатом (200 мс, tabular-nums). Плашка-«пилюля» по касанию раскрывается
   в список выбранного (morph: высота/радиус, 220 мс), как Morph island из ПРИЁМЫ.
4. Подсказка комбинации (см. логику калькулятора) выезжает строкой под Summe, не модалкой.
5. Подбор процедуры: результат раскрывается под третьим вопросом (height transition), прокрутка мягко доводит до него.
6. Меню-шторка снизу (transform, 240 мс). Карточка записи появляется 0.96→1 + тень (200 мс).
prefers-reduced-motion: всё мгновенно, блик героя не идёт, вибрации нет. Анимировать только transform/opacity/SVG-атрибуты.
GSAP не нужен; всё на CSS + несколько строк JS.

Блок 3. «Welche Gesichtsbehandlung passt zu mir?» (какой уход за лицом мне подходит) — подбор, компактно.
  Три вопроса чипами, по одному ряду (на телефоне ряды переносятся, чипы крупные):
   1 «Was wünscht sich Ihre Haut?» (чего хочет ваша кожа): Ruhe bei Rötungen (покой при покраснениях) ·
     Klarheit bei Unreinheiten (чистота при высыпаниях) · Feuchtigkeit (увлажнение) · Frische und Glätte (свежесть, гладкость) ·
     Einfach entspannen (просто расслабиться)
   2 «Wie viel Zeit haben Sie?» (сколько времени): bis 45 Min. · 60 Min. · 90 Min. und mehr
   3 «Was mögen Sie lieber?» (что предпочитаете): Zuckerpflege (уход с сахарной пастой) · Naturkosmetik mit Kräuter-Tonics
     (натуральная косметика с травяными тониками) · Klassisch (классика) · Egal, beraten Sie mich (всё равно, посоветуйте)
