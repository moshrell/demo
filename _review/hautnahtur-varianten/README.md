# Hautnahtur: три направления редизайна (эскизы, 26.11.2026)

Повод: опубликованная версия (kravets-webdesign.de/arbeiten/hautnahtur/) слишком тёмная, медовая капсула внизу с чёрной кнопкой выглядит тяжело.
Эскизы: первый экран телефона, блок цен на телефоне, первый экран ПК. Это быстрые макеты (не сайт): видео показано первым кадром.

- **A, светлый** (`A-hell.jpg`): почти белый фон, шрифт Figtree, один акцент — оранжевый из её логотипа. Видео в скруглённом «окне» под заголовком (ПК: справа). Нижняя панель белая, кнопка оранжевая.
- **B, кино** (`B-kino.jpg`): видео на весь первый экран, чёрный фон, тонкий шрифт Hanken Grotesk, цвет только в видео. Нижняя панель — тёмное стекло, кнопка светлая.
- **C, карточка** (`C-karte.jpg`): тёплый светлый фон, видео и текст собраны в одну большую карточку (видео сверху, текст на тёмно-кофейном снизу; ПК: видео слева, текст справа). Шрифт Bricolage Grotesque, плотный. Панель кофейная, кнопка оранжевая.

Известно по эскизам: в C на телефоне кнопка героя уходит под панель (в сайте поправить высотой видео).
