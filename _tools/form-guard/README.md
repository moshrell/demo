# form-guard: защита форм

Одна библиотека для всех форм, которые что-то отправляют (сайт kravets-webdesign.de и сайты клиентов).
Мастер-копия: `form-guard.php` в этой папке. В проектах лежат копии; правки вносить сюда, потом раскладывать.

Где сейчас используется:
- `kravets-site/public/form.php` (Kontakt и Fragebogen, de/en/uk)
- `_template/server/form.php` (приёмник для `OrderForm.astro` у настоящего клиента)

## Что закрывает
- **Ссылки.** `fgHasLink()` находит `https://…`, `hxxp://…`, `www.…`, домены вида `name.de`, `name[.]com`, `name(dot)xyz`,
  `spam . com` (с пробелами только длинные TLD строчными), `t.me/…`, `bit.ly/…`, кириллические `.рф`, IP-адреса.
  E-mail (`anna@salon.de`) ссылкой не считается. Сокращения и имена (`Dr. med.`, `Fr. De Vries`, `Bahnhofstr. 15`, `z. B.`) тоже.
- **Обезвреживание.** `fgDefang()` превращает ссылку в `hxxps[://]salon[.]de`: человек прочитает, почта не сделает кликабельной.
- **Скрытые символы.** `fgLine()` / `fgText()`: убирают управляющие, zero-width, смену направления текста (U+202E), битый UTF-8;
  однострочные поля без переводов строк (заголовки письма не подделать).
- **Частота.** `fgRateLimit()`: счётчик по псевдониму IP (HMAC, ключ меняется каждый день, IP не хранится, файлы старше двух дней удаляются).
  Хранилище `_form-data/` рядом с файлом (закрыто `.htaccess`) или временная папка сервера. Если писать некуда, форму не блокирует.
- **Чужие сайты.** `fgSameOrigin()`: POST только со страниц этого домена.
- Прямой вызов `form-guard.php` из браузера отвечает 404.

Остаётся в самой форме: скрытое поле-ловушка `website`, метка времени `ts` (меньше 3 секунд = бот), письмо только текстом, без вложений.

## Политика по полям
- Имя, телефон, название, выбор услуги: ссылка = отказ с понятным текстом.
- Свободный текст: у клиента по умолчанию отказ (`NOTE_LINKS = 'block'`), у kravets-site обезвреживание
  (клиенты присылают адрес своего старого сайта). Много ссылок сразу = спам: «успех» без отправки.

## Проверка
`php test/unit.php` (нужны PHP 8.1+ и mbstring): списки «должно быть ссылкой» и «не должно» плюс чистка символов. Должно быть `UNIT OK`.
При новых ложных срабатываниях дописать пример в `$no` и поправить регулярку.

## Datenschutz
Лимит хранит псевдоним до двух дней, поэтому на сайте с формой нужен абзац «Schutz vor Missbrauch»
(Art. 6 Abs. 1 lit. f DSGVO). В шаблоне: `<DatenschutzForm live />`, у kravets-site уже в `datenschutz.astro`.

## Известные ограничения
- Ссылку можно замаскировать словами («spam punkt de»): такое не ловим, чтобы не резать обычный текст. Письмо всё равно текстовое и некликабельное.
- Лимит считает по IP: за одним роутером (офис, общежитие) несколько человек делят 5 заявок в час.
- `mail()` хостинга: у клиента обязательно отправитель на его домене (SPF), иначе письма уходят в спам.
