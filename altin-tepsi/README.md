# Altın Tepsi

Astro-Projekt (Demo). Адрес на портфолио: `/vorschau/cafe/altin-tepsi/`

    START.bat           # первый запуск ставит пакеты, дальше dev-сервер
    npm run build       # сборка + удаление неиспользуемых оригиналов фото + плашка ИИ + dist/.htaccess (CSP с хэшами, noindex)
    npm run publish     # сборка + копия в ..\kravets-site\public\vorschau\cafe\altin-tepsi

## Идея
Страница = сборка коробки. Hero: поднос (Tepsi) один раз наполняется выпечкой. Дальше список сортов с фото-сценой,
конфигуратор коробки (размер, сорта, цена на лету, заказ готовым сообщением: e-mail, WhatsApp или звонок), готовые подарочные коробки,
калькулятор для компаний (B2B), «О нас», контакты с живым статусом «Jetzt geöffnet» (сейчас открыто, берлинское время).

## Где что
- Тексты, цены, часы, готовые коробки, параметры B2B: `src/data/shop.json` (всё вымышлено, демо).
- Фото: `src/photos/`, имена и промпты в `PHOTOS.md`.
- Цвета, шрифты, отступы: `src/styles/tokens.css`. Вёрстка: `src/styles/global.css`.
- Выпечка как SVG: `src/lib/pieces.ts`. Логика (коробка, статус, калькулятор): `src/scripts/page.js`.
