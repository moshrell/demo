# Backstube Morgenrot

Astro-Projekt (Demo). Адрес на портфолио: `/vorschau/cafe/backstube-morgenrot/`

    START-PHONE.bat     # то же, но сайт доступен с телефона по Wi-Fi (адрес печатается в окне)
    START.bat           # первый запуск ставит пакеты, дальше dev-сервер
    npm run build       # сборка + удаление неиспользуемых оригиналов фото + dist/.htaccess (CSP с хэшами, noindex)
    npm run publish     # сборка + копия в ..\kravets-site\public\vorschau\cafe\backstube-morgenrot

## Идея
«Standbild-Tag» (Standbild = неподвижный кадр): одна камера внутри пекарни, 10 кадров дня (4:30 … 18:30), поверх них 6 карточек (4:30, 6:00, 8:00, 11:00, 15:00, 18:30).
Скролл крутит часы в шапке и плавно перетекает от кадра к кадру по времени. В конце дня форма «Die Tüte für morgen» (пакет на завтра).
Живое: статус «Jetzt geöffnet» (сейчас открыто) по берлинскому времени и ссылка «Zu … Uhr springen» на подходящий час.

## Где что
- Тексты, цены, часы, отзывы: `src/data/bakery.json` (все данные вымышленные, демо).
- Фото: `src/photos/` (f01…f10 + bag), имена и промпты в `PHOTOS.md`. Кадры и их минуты: `frames` в `bakery.json`.
- Цвета, шрифты, шесть «световых фаз»: `src/styles/tokens.css`. Вёрстка: `src/styles/global.css`.
- Скролл-логика, часы, форма: `src/scripts/page.js`.
- Форма заказа демонстрационная, ничего не отправляет. Для клиента подключать отправку на его почту.

## Для реального клиента
Фото, адрес, отзывы и подвал «Demo-Website» заменить настоящими (отзывы только настоящие), юридические страницы заполнить его данными.
