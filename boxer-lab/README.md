# Лаборатория: 3D-механизм, нарисованный кодом (boxer-lab)

Статус: **тест подхода, не демо клиента.** Живая версия: https://moshrell.github.io/demo/boxer-lab/
Вопрос теста: можно ли нарисовать кодом (three.js, без Blender и готовых моделей) механизм такого качества, чтобы он годился в портфолио.
Ответ первого прохода: механика и материалы выглядят прилично; головки цилиндров пока «кубики».

## Что внутри
- `src/lab/kin.js`: чистая математика оппозитного шестицилиндрового мотора (кривошипно-шатунный механизм). Проверка: `npm run check` (ВМТ каждого цилиндра в момент его зажигания, порядок 1-6-2-4-3-5 через 120°, зеркальные пары, зазоры).
- `src/lab/engine.js`: геометрия кодом (тела вращения, выдавливание, трубы); `update(угол)` ставит все детали только из `kin.js`.
- `src/lab/main.js`: студия (светлый фон, один акцент: оранжевое горение в рабочем цилиндре), 5 видов камеры, упрощённое качество на телефоне, прогрев шейдеров до первого кадра.
- `tools/shots.mjs`: контактные листы стоп-кадров для самопроверки (`DEMO_BASE=/ npx astro build`, затем `node tools/shots.mjs out.png "130:hero,70:front" 2 800x450`).

## Цифры ПРИДУМАНЫ, не взяты с реального мотора
Диаметр цилиндра 97 мм, ход 81,5 мм, шатун 130 мм, шаг цилиндров 152 мм → 3614 см³ (посчитано). Порядок работы и 120° — стандартная схема оппозитной «шестёрки». Перед любой подписью «это мотор X» заменить на цифры из источника.

## Известные недочёты
- Головки, крышки, свечи — простые блоки: нет клапанов, распредвалов, реальной формы головки.
- Вид «Cylinder» смотрит на один цилиндр и не следует за горящим; нужен выбор цилиндра.
- На реальной видеокарте и телефоне не проверено: стоп-кадры рендерились программно (swiftshader), FPS неизвестен.
- Компиляция шейдеров может на мгновение подвесить слабый телефон: не измерено.
- Нет панелей с живыми цифрами, автотура с курсором, звука, видео.
- Нет вращения пальцем (только кнопки видов).

## Источники и лицензии
three.js (MIT). Правила (сначала референс, реальные числа, один вход двигает всё, проверка по стоп-кадрам) взяты из скилла `teardown` (elvarofficial, MIT) и `claude-motion` (whaleyxbt, MIT); их код не копировался. Оба репозитория проверены сканером NVIDIA SkillSpector: вредоносного не найдено.
