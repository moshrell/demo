# Fernpunkt — демо «оптик» (Augenoptiker)

Вымышленная оптика в Hannover-List. Адрес для просмотра: https://moshrell.github.io/demo/fernpunkt/
Имя проверено поиском 12.11.2026: оптики «Fernpunkt» и «Brandhorst» в Ганновере не найдены.

## Чем отличается от остальных демо
- **Шапка**: липкой полосы нет. Навигация в форме очков (внизу на телефоне, справа вверху на ПК): левое стекло = меню, правое = запись. На странице стёкол правое стекло показывает текущую сумму, на странице записи = звонок.
- **Меню**: во весь экран, строки уменьшаются сверху вниз, как таблица для проверки зрения.
- **Первый экран**: заголовок набран таблицей зрения, нижние строки размыты, линзу можно двигать пальцем.
- **Футер**: салфетка для очков с зубчатым краем, под ней строка мелким шрифтом.
- **Механики**: примерка (модель + камера), схема зон прогрессивного стекла (Gleitsicht), калькулятор стёкол с итогом и срезом линзы, запись с выбором дня.
- Палитра: баклажан + холодное стекло + блик просветления. Шрифты: Bodoni Moda + Schibsted Grotesk.

## Примерка
- Оправы нарисованы кодом по параметрам (`src/lib/frames.ts`, мм). Один источник для каталога (SVG) и примерки (canvas).
- На странице (`Buehne.astro`, `scripts/buehne.ts`): фото-модель, точки лица посчитаны заранее (`src/data/models.json`), MediaPipe не грузится. Новая модель: фото анфас в `public/img/`, дописать в `tools/landmarks.mjs`, запустить `node tools/landmarks.mjs`.
- **Камера на весь экран** (`Kamera.astro`, `scripts/kamera.ts`): открывается прямо кнопками «Brille anprobieren» / «An mir selbst anprobieren» (`[data-kamera-auf]`), отдельной страницы нет. Внизу круглые иконки оправ, над выбранной цвета столбиком, сверху закрыть и «запомнить».
- Устройство: кадр камеры идёт в обычном `<video>` (всегда плавно), поверх прозрачный canvas только с оправой. Распознавание лица (MediaPipe, CPU) работает отдельно и на слабом телефоне само реже обновляет оправу, а видео не тормозит. Всё на устройстве.
- Загрузка с индикатором: запрос камеры и загрузка движка идут параллельно, кольцо показывает процент. Модель `public/mp/face_landmarker.task` урезана (убраны blendshapes, 2,8 МБ вместо 3,7). WASM (~15 МБ, по сети ~4 МБ в gzip) копируется из `node_modules` при сборке (`astro.config.mjs`). Итого около 8 МБ по сети при первом открытии, дальше из кэша.

## Проверено
- `tools/pagecheck.mjs` на 390x844, 360x740, 768x1024, 844x390, 1440x900: чисто (в отчёте только намеренные горизонтальные ленты оправ и дней).
- Сценарий в headless Chrome с подставной камерой: камера открывается на весь экран, оправа садится на лицо, смена оправ и цветов не останавливает кадр, закрыть и открыть заново, отказ в доступе даёт понятное сообщение и кнопки; отложенное → калькулятор → запись, итог сходится, ввод не теряется после перехода на Datenschutz, согласие не восстанавливается.

- Шрифт Bodoni: волосяные линии утолщены (фиксированная оптическая ширина opsz 8–14, вес 600–700), чтобы текст читался при слабом зрении. Шрифт оставлен ради характера, смотреть можно в `global.css`.

## Не проверено / известные недочёты
- **Камера на реальных телефонах** (iPhone Safari, слабый Android): скорость, дрожание оправы, первая загрузка ~8 МБ. Проверить руками.
- Оправа плоская: при сильном повороте головы выглядит менее правдоподобно, чем 3D-модель.
- CSP для All-Inkl: в `scripts/htaccess.mjs` добавлено `'wasm-unsafe-eval'`; на живом хостинге с этим CSP камера не проверялась. Сжатие `.wasm` и кэш `/mp/` включены в `.htaccess` (нужны mod_deflate, mod_headers).
- Фото с Unsplash (лицензия Unsplash, авторы на странице Impressum). При желании заменить своими кадрами под теми же именами в `public/img/`.
- Цены условные.
