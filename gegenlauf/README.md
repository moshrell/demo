# Gegenlauf Sportwagenservice (Demo)

Независимая мастерская Porsche в Ганновере (вымышленная). Главная механика: машина в ночном шоуруме →
«рентген»-кузов и узлы шасси → список услуг с ценами по модели → Summe (итог) → заявка.
ТЗ: `TZ.txt`. Просмотр: https://moshrell.github.io/demo/gegenlauf/ · только сцена: `/demo/gegenlauf/studio/`.
Адрес на портфолио: `/vorschau/auto/gegenlauf/`, превью для `kravets-site/public/works/`: `preview.webp` (16:10).

    START.bat           # первый запуск ставит пакеты, дальше dev-сервер
    npm run build       # сборка + dist/.htaccess (CSP с хэшами, noindex)
    npm run publish     # сборка + копия в ..\kravets-site\public\vorschau\auto\gegenlauf

## Этап 0: какая машина и почему
Рабочая модель: **C, «Porsche 911 with interior»** (n.brizitskaya, Sketchfab, CC BY 4.0). Запасная B (2015 Carrera S)
не понадобилась и в сцене не рендерилась.

| | C (выбрана) | B (запас) |
|---|---|---|
| Исходник | 43 МБ, 380 тыс. треугольников, 36 материалов | 174 МБ, 322 тыс. треугольников, текстуры-атласы 4K |
| Узлы | по материалам; кузов, двери, стёкла, фары, колёса, тормоза, насадки выпуска отдельно | по деталям, но лак запечён в текстуру-атлас |
| Свой лак | да: кузов отдельным материалом, тени стыков запечены | трудно: цвет кузова в общей текстуре |
| Признаки выдирания из игры | не найдено (имена материалов авторские, экспорт из 3ds Max/FBX, нет LOD-цепочек и игровых имён) | имена на пиньине (`waike_t`), похоже на переработку чужой модели: при покупке проверять |
| Эмблемы | гербы и надписи отдельным материалом + буквы на корме: убраны | не проверялось |

Как C выглядит в шоуруме, проверено по стоп-кадрам (3/4 спереди и сзади, бок, фара со стыками, колесо, корма):
кузов гладкий, стыки читаются, блики идут ровными полосами. Заметные слабости: тени стыков запечены в текстуру
1024 px, вблизи у фары и крыла видны мягкие пятна; салон упрощён до тёмных объёмов (стёкла затемнены).

## Что сделано с моделью (`tools/prep-model.mjs`)
Исходник в git не хранится (`_models/` в `.gitignore`), лежит у Степана. Скрипт: закрывает открытую дверь, удаляет
эмблемы (материал `LOGO1`: герб на капоте, колпаки, руль, шильдики), хромированные буквы на корме и шильдик модели,
выдавленные буквы в световой планке закрывает гладкой планкой, размывает следы эмблем в запечённой тени, номер
заменяет на «DEMO», ставит машину носом в +Z на пол, раскладывает по группам сцены, облегчает и сжимает (meshopt, WebP).

- Результат: `public/models/fahrzeug.glb`, **1,38 МБ**, 144 тыс. треугольников машины + 23 тыс. облегчённая
  «рентген»-оболочка, 32 примитива. Замеры (центры колёс, диски, профиль кузова): `public/models/fahrzeug.json`.
- Запуск: `node tools/prep-model.mjs _models/c/porsche_911_with_interior.glb`
- Вторая машина: новый файл + запись в `src/data/fahrzeuge.json` (файл, размеры, автор, лицензия). Зоны и цены общие.
- Оставшийся след товарного знака: форма кузова 911 сама по себе. Это осознанный риск из ТЗ; при продаже
  мастерской другой марки машина меняется.

## Узлы под кузовом (`src/scene/chassis.js`)
Построены кодом, **схематично**: расположение и пропорции по замерам модели и открытым данным о компоновке, это не
копии реальных деталей (подпись «Schematische Darstellung» = «схематичное изображение» стоит под сценой).
- Размеры 911 Turbo S (992): 4535 × 1900 × 1303 мм, колёсная база 2450 мм, колея 1583 / 1600 мм
  (auto motor und sport, технические данные 992 Turbo; ADAC Autokatalog). По модели: база 2452 мм, длина 4535 мм,
  высота 1310 мм, колея по шинам ≈1557 / 1570 мм, диски 420 / 390 мм.
- Мотор: оппозитная «шестёрка» за задней осью, шаг цилиндров из `boxer-lab` (`src/scene/kin.js`), статичный.
  Коробка перед мотором, дифференциал на линии задней оси, аккумулятор и бак спереди.
- Тормозные диски, суппорты и насадки выпуска взяты из модели машины.
- Условности: услуги для 986–997 и 964/993 показываются на машине 992 (пример из ТЗ); масляный фильтр, свечи и
  катушки стоят сверху, чтобы их было видно с камеры; IMS-вал и сцепление светятся сквозь корпус.
- При «рентгене» кузов поднят на 12 см, поэтому глушитель и поддон видны ниже заднего бампера: так задумано.

## Данные (при покупке меняются только они)
- `src/data/betrieb.json`: название, мастер, адрес, часы, тексты блоков, случаи, FAQ.
- `src/data/preise.json`: таблица модель × услуга × цена, зоны, состав услуг, какие узлы подсвечивать (`teile`).
- `src/data/fahrzeuge.json`: машина в сцене, размеры, автор и лицензия.
Цены демо: рыночный порядок, 986/987 ×1,0 · 996/997 ×1,1 · 964/993 ×1,25, округлены; IMS только 986/996/997,
Ventilspiel только 964/993, Fehlerdiagnose 89 € для всех. «Anderes Modell» (другая модель): цены «auf Anfrage» (по запросу).
Вымышленное: Gegenlauf, Jörn Halvesen (поиск «Halvesen Porsche Werkstatt Hannover»: совпадений нет), адрес с домом 0,
телефон из «Drama Numbers» (030 23125 911), почта `@example.com`.

## Запасные режимы
- Нет WebGL2, `saveData`, сеть 2g: постер + 7 кадров зон из этой же сцены (`public/img/szene/`), чипы и цены работают.
  Проверить вручную: `?ohne3d` в адресе.
- Слабое устройство: первые 45 кадров меряется время кадра; >30 мс — ниже разрешение, >55 мс — без прохода глубины
  и pixelRatio 1, >110 мс — переход на кадры.
- `prefers-reduced-motion`: без пробуждения, перелётов и счётчика, состояния меняются сразу.
- Без JavaScript: услуги с ценами для 986, таблица всех цен, форма как обычный HTML, чипы зон = якорные ссылки.

## Что проверено и как
- `tools/flow.mjs` (390×844, 320×640, 1440×810, reduced-motion, без 3D): 987 → Kleine Wartung 590 → + Zündkerzen 830
  → + Bremsflüssigkeit 950; смена модели пересчитывает; выбор переживает перезагрузку; форма с подставленными
  моделью и услугами; ошибки пустой отправки; подтверждение со сроком звонка; нет горизонтальной прокрутки;
  зоны нажатия ≥ 44 px; консоль без ошибок.
- По снимкам (headless Chrome, программный рендер) пройдена вся страница сверху вниз: телефон 390 и 320,
  альбомная 844×390, планшет 768×1024, ПК 1440, страницы Impressum и Datenschutz на 390. Найдено и исправлено:
  страница открывалась не сверху, невидимый блок-прокладка, видимое подтверждение под формой до отправки,
  английская кнопка выбора файла, обрезанная лента зон и плавающая плашка поверх текста на ПК, сирота-карточка на планшете.
  Ранее по снимкам: ПК 1920, режим без 3D, режим без JS. На 1920 и в режиме без JS последний обход не повторялся.

## Не проверено / известные недочёты
- **Реальный телефон не проверялся.** Плавность, время до живой сцены, наклон пальцем, ступени качества, сон вкладки
  и возврат — только на устройстве Степана. Нужно: открыть ссылку на телефоне по мобильной сети.
- Safari/iOS не проверялся (только Chromium).
- Lighthouse не запускался; LCP и CLS не измерены (постер с заданными размерами, шрифты `swap`).
- Контраст измерен не инструментом, а по токенам: текст `oklch(95%)` и `oklch(76%)` на фоне `oklch(17%)`.
- Юридический текст FAQ про гарантию (VO (EU) Nr. 461/2010) — формулировка демо, клиент согласует со своим юристом.
- Фото: файлов из `PROMPTS.txt` ещё нет, блоки фото скрыты, в случаях стоят кадры сцены.
- Запасная модель B не подготовлена (`prep-model.mjs` настроен на материалы модели C).
- На kravets-site нужно, чтобы `scripts/htaccess.mjs` разрешал `'wasm-unsafe-eval'` и `blob:` в `connect-src`
  (в этом проекте уже добавлено).
