# Glanzleistung — демо-сайт автодетейлинга (Fahrzeugaufbereitung)

Портфолио-демо Kravets Webdesign. Вымышленный бизнес «Glanzleistung», Gehrden (Musterweg 1).
Сайт-«гараж» (телефон — главный экран, широкий экран — гараж на весь экран): интро-заезд → **Box** (бокс с BMW M6 Cabrio) → тап по услуге → камера летит
к машине → панель с ценой → заказ (Auftrag) → печатается чек. Всё на немецком, комментарии в коде — тоже немецкие.

## 1. Правила работы с владельцем (Степан)

- Общение по-русски, коротко, без «может быть». Немецкие слова сразу расшифровывать в скобках.
- Пути всегда как в проводнике Windows (`D:\Webdesign\…`). Файлы в чат не слать — класть в папку проекта.
- Mobile first. Любая видимая ошибка на презентации = провал: проверять скриншотами, а не «должно работать».
- Сначала продумать пользовательский путь и логику, потом строить. Предлагать варианты решений (A/B/C).
- Фото не генерировать: только `.txt` с готовыми промптами для Gemini (форматы 1:1, 9:16, 16:9, 3:4, 4:3), он сам кладёт картинки в папку.
- Формы: плейсхолдеры-примеры, согласие на Datenschutz, итоговая сумма видна всегда; введённые данные не теряются никогда.
- Коммитить можно свободно (все незакоммиченные изменения — от Claude). Удалять неиспользуемые файлы можно.

## 4. Архитектура сцены

### 4.1 Слои (в `[data-frame]`, ширина колонки `--col`, высота 100svh)
1. **`canvas[data-bgcv]`** — Box-картинка и крупный план инфо-станции **рисуются в canvas** (`drawBg()`),
   размером с экран × DPR (максимум 2.5). Это главная защита от «чёрных текстур» (см. раздел 6).
   `<img data-img-clean>` и `<img data-st-img>` скрыты (`.src-img`) и служат только источником.
2. **`.world[data-world]`** 1440×2560 (на десктопе 2560×1440), `transform: translate/scale` = камера Box. Внутри: `.surf` (неон-табло и карта, перспектива `matrix3d` по углам из Blender), `.hotspots` (точки на машине).
3. **`.world--st[data-stworld]`** — только HTML-оверлеи станций (`.ov`: текст на табло, чек на кассе, страница
   Gästebuch, Sicherungskasten) в перспективе; прозрачность = кроссфейд к крупному плану (`stage.stOp`).
4. **`.world--clip[data-clipworld]`** 720×1280 — видео пролёта + стоп-кадр + `[data-clip-tint]` (капот в цвете плёнки)
   + `[data-clip-canvas]` (класс `Scrub`: «грязный → чистый» с бликом через 1 с).

### 4.2 Камера
- `stage.cam = {s, tx, ty}` для Box; `applyCam()` ставит transform и вызывает `drawBg()`.
- `camTo()/clipCamTo()` — твины (`tween`), логарифмический зум. `camToken` отменяет старую анимацию.
- Во время любой `camTo` у body класс **`is-flying`**: хотспоты скрыты, `--ws` не меняется (иначе весь Box-слой
  перерисовывается каждый кадр).
- `clampCam` — кадр всегда закрыт картинкой (никаких серых полос). `visible()` — зона между HUD и открытой панелью.
- `zoomTarget(z)` для станций с `view.zoom` (Felgen, Folie): `x, y, yb` (нижняя граница машины над панелью), `xr`
  (правый край), `z` (зум, максимум base×1.7). `infoTarget(id)` — для инфо-станций. `clipTarget(name)` + `CLIP_WIN`.
- `refit()` / `refitAnimated()` — подгонка при ресайзе и при перетаскивании панели.

### 4.3 Как показывается услуга (`services.json → view`)
| Услуга | view | Что происходит |
|---|---|---|
| Lack | `clip: lack, zone: lack` | видео-пролёт → стоп-кадр «stumpf» → через 1 с блик и чистый чёрный лак |
| Felgen | `zoom` | зум Box на переднее колесо вместе с крылом |
| Innenraum, Ozon, Dachhimmel | `clip: interior` | пролёт в салон, стоп-кадр |
| Folie | `zoom` | вся машина, цвет и отделка = реальный рендер (кроссфейд); у хамелеона свайп-наклона больше нет |

Если в заказе есть плёнка (не `original`): видео не играет (оно снято на чёрной машине), только кроссфейд;
в Lack показывается рендер капота `wrap/*/hood-…`, у Felgen на десктопе — мягкий зум по рендеру бокса.
Цвет выбирается через `wrapOf(sel)` → `boxUrl()` → `setBox()`; перекраски в браузере (tintCanvas, paint-пассы) больше нет.
Салон остаётся в оригинальной краске.

### 4.4 Состояние
- `sessionStorage['gl:state:v2']`: `{vehicles:[{id, cls, items:{svcId:{level, addons, opt, color, finish}}}], active}`.
- Форма заказа: `sessionStorage['form:gl-auftrag']` (сохраняется на каждый ввод; Datenschutz-галочка не хранится).
- Цены: `lineItems(v)`, `totals()`; цена = база × множитель класса, округление до …9.

### 4.5 Панели (Sheets, `<dialog>`)
- **Cam-sheets** (`.sheet--cam`: station, zeiten, anfahrt, funk, gaestebuch, recht, auftrag) — немодальные, камера
  остаётся видна. Появляются после прилёта камеры (`is-pre` → `reveal`).
- **Модальные** (klasse, fahrzeug, menu, preise) — `showModal`. Если модальная открыта поверх станции, станция
  остаётся «под ней» (`under`), после закрытия возвращаемся на станцию (с новой ценой).
- История: каждая панель = запись в `history` (кнопка «назад» на Android закрывает панель). `skipPop` гасит
  собственный `history.back()`.
- Перетаскивание за шапку (`bindSheetDrag`): вверх — 92 % экрана, вниз — свёрнута до шапки; тап по свёрнутой —
  обратно. Только на мобильной раскладке.
- HUD: на станции стрелка «назад», в Box — меню (`syncHud`).
- Fahrzeug («Was fährst du?»): выбор класса применяется сразу и закрывает окно; «Fertig» для прочего.

### 4.6 Заказ и чек
- Termin anfragen доступен всегда (пустая корзина = «Beratung vor Ort», консультация на месте).
- Чек в Auftrag-панели «печатается» целиком из щели (`.slot > .slot__win > .ticket.is-print`, `steps(34)`),
  зубчатый низ — CSS-маска (без псевдоэлементов).
- После отправки: итоговый чек (номер GL-xxxx, дата, услуги, сумма, текст «Wir melden uns…»).
  Wunschtermin (желаемая дата) и Hol-/Bringservice — под чеком, не в нём. Форма ничего не отправляет (демо).

### 4.7 CSP
`.htaccess` разрешает только хешированные инлайн-стили. Значит: **никаких `style="…"` в строках innerHTML**,
стили — через CSSOM (`el.style.x = …`) или классы/`data-*`. Атрибуты `style` в `.astro` можно (они хешируются при сборке).

## 4.8 Десктоп, планшет и промежуточные размеры
У каждого экрана своя раскладка (не растянутая телефонная).
- Режим выбирается медиа-запросом `DESK_Q = (min-width: 640px) and (min-aspect-ratio: 5/4)` (app.js; `html.desk`, `G.desk`).
- **Десктоп (и планшет/телефон в ландшафте):** справа сплошная **боковая панель-конфигуратор** (`.wall`, ширина `--side` = clamp(340px, 30vw, 500px)):
  название, выбор класса кнопками (`data-set-cls`), услуги списком с описанием (`svc__s`) и ценой, пять кнопок мастерской (Zeiten, Anfahrt, Boxenfunk, Gästebuch, Recht),
  внизу липкая «Summe + Termin anfragen» (`.side__cta`, `data-sum-mirror`). HUD слева без класса и суммы.
  Панели станций и заказа открываются на месте боковой панели во всю высоту; меню, все цены, выбор класса и машины — окном по центру.
  Кадр Box на десктопе сдвинут (`baseCam`), чтобы машина стояла по центру свободной части слева (важно для 4:3 / iPad в ландшафте); перед клипом камера возвращается к несдвинутому кадру.
  Высота 621–880 px: список плотнее; ≤ 620 px (телефон в ландшафте): компактная панель, услуги плитками 3×2.
- **Планшет вертикально** (≥ 700 px, телефонная сцена): бокс во всю ширину до 4:5 (`--col`), шесть услуг в один ряд, крупный док и HUD, панели как плавающая карточка снизу (до 640 px).
- **Телефон**: как было (колонка, 4 точки, карточки услуг на полу).
- На машине мигают только 4 точки; остальные пины (`hs--dk`, `data-pin-open`) на десктопе скрыты.
- Смена размера окна на лету (`switchMode`): камера и картинки пересчитываются, выбранная плёнка сохраняется (тест «Fenster ziehen»).
- Клипы десктопа 1280×720 (lack, wheel, interior) + стоп-кадры; Felgen на десктопе: клип с чёрной машиной, а с плёнкой — зум по рендеру.

## 6. Чёрные/пропадающие текстуры — причина и решение (важно!)

Симптом (Android и десктоп Chrome): после приближения к объекту Box становился чёрным, или картинка Box рисовалась
маленьким прямоугольником со смещением.

Найдено через Chrome-трейс (`cc` / `LayerTree`), см. `tests/layers3.cjs`:
1. Box-картинка 1440×2560 жила в `.world` с `will-change: transform` и масштабом от 0.33 до ×7.
   Chrome растрирует такой слой в одном масштабе и потом меняет его рывками; первый растр шёл в масштабе 1
   (до JS) → на телефоне DPR 2.75 это ~110 МБ GPU для одного слоя. Под нехваткой памяти — чёрные плитки
   или плитки старого масштаба (картинка «уменьшенная»).
2. Хотспоты меняли `scale` через `--ws` каждый кадр → весь Box-слой перерисовывался 47 раз за один пролёт.
3. Карта на постере была inline-SVG в 3D-перспективе → перерастр каждый кадр (58 раз за пролёт).

Решение: Box и крупные планы рисуются в **canvas размером с экран** (`drawBg`, память постоянная ~10 МБ),
хотспоты скрыты во время пролёта, карта стала картинкой, у `.surf` — `will-change`. Пиковая GPU-память плиток
упала с ~32 МБ до ~12 МБ (при DPR 1; на телефоне выигрыш ×7). Размытие `backdrop-filter` убрано везде.
При возврате на вкладку — `recoverTextures()` (перерисовать canvas, проверить картинку).

**Правило на будущее:** не класть большие картинки в слои, которые масштабируются JS-ом в широком диапазоне;
не анимировать CSS-переменные, от которых зависит transform детей большого слоя; проверять `tests/layers3.cjs` (в headless-shell дерево слоёв может быть пустым: `layers=0` — тогда смотреть в обычном Chrome → DevTools → Layers)
(в выводе не должно быть «REPAINT … DIV.world» или «.surf» на десятки раз).

## 7. История решений (коротко)
- Грязь/протирание убраны: машина сразу чистая, Lack и Felgen сами «полируются» через 1 с.
- 6 карточек услуг на полу под машиной (с ценами «ab»), док внизу: Zeiten, Anfahrt, Boxenfunk, Gästebuch, Termin.
- Класс авто спрашивается один раз при первом тапе по услуге (фото классов).
- Дизайн: графит + слоновая кость, шрифт Onest; неон только в сцене (не в интерфейсе).
- Folie: заказать онлайн можно только Vollfolierung (цвет + matt/satin/glanz), без новых рендеров. Akzentstreifen и Dach & Spiegel (полоса, крыша и зеркала) есть только в прайсе со звёздочкой (`onRequest` в services.json, «по запросу в сообщении»). Поэтому плитка показывает «ab 2.289 €», а цвет по умолчанию — Candy Kirsch без доплаты за спецплёнку (25.11.2026).
- Цены в services.json уже округлены до …9 (как `priceFor`), прайс (`PriceTable.astro`) одинаковый в меню и в классическом виде; на телефоне каждая услуга — строка с четырьмя классами под ней.
- Felgen: не видео-клип (колесо вблизи некрасиво), а зум Box с крылом.
- Sicherungskasten (Impressum/Datenschutz/Lizenzen) — светлая табличка на щитке.
- Интро: новые рендеры v4 (8 с), кроссфейд 0,3 с в бокс.

## 8. Пасхалка «Quersteher-Challenge» (готова)
Один круг по ночной парковке против призрака, награда — код −10 %.
- **Вход:** Anfahrt-станция (карта-постер) → в тупике у Glanzleistung припаркованная машинка (`[data-qs-hook]`), держать 1 с («Handbremse»). Через 20 с на станции машинка один раз моргает фарами. Клавиатура: Enter на кнопке.
- **Управление:** левая/правая половина экрана = руль, обе = тормоз, потом задний ход. Газ автоматический. Клавиши ←/→/↓ (A/D/S, пробел).
- **Код:** `QS-<время в сотых>-<2 знака>` (`src/scripts/quersteher/code.js`, проверка только в браузере, это демо; у настоящего клиента код фиксированный или проверка на сервере). Поле «Aktionscode» в заказе принимает и `QUERSTEHER`, и такие коды; скидка −10 % не на Folie. Ввод не теряется (sessionStorage), неверный код блокирует отправку.
- **Файлы:** `src/scripts/quersteher/` (`track` трасса, `sim` физика, `game` экран, `ghost` записанный проезд, `code`), грузится отдельным чанком только при старте игры (~14 КБ gzip). Стили в конце `global.css`.
- **Машинка:** `public/media/quersteher/car_base.png` + `car_mask.png` (из Blender: вид сверху, нос вверх, 224×432; маска белым = красится). Цвет = выбранная Folie (иначе серебро). Без файлов рисуется запасная машинка.
- **Сложность** (замер ботами, `scripts/quersteher-tools/`): идеальный круг 24,8 с, «неуверенный палец» ~33 с, призрак = идеал × 1,17 ≈ 29 с. После 3 проигрышей кнопка «Geist langsamer» (−10 % за нажатие, до 3 раз). Параметры: `GHOST_BASE` в `game.js`, физика `P` в `sim.js`. После правки физики или трассы пересобрать призрака: `node scripts/quersteher-tools/makeghost.mjs`, замер: `node scripts/quersteher-tools/calib.mjs`.
- **DSGVO:** игра ничего не отправляет; лучшее время в localStorage `gl:qs:best` (описано в Datenschutz).
- Тест: `node tests/qs.cjs` (на :4400 с CSP, `?qsdebug=1` включает отладочный объект `window.__qs`).

## 9. Тесты (облачный контейнер Claude)
Playwright + headless Chromium (путь `CHROME=…`, модуль `PW=…`, `lib.cjs` — общие помощники: `open`, `px` = реальные пиксели canvas, `ok`).
```
npm run build && node tests/csp-serve.cjs &         # dist с настоящим CSP на :4400
node tests/flow.cjs     # телефон: услуги, класс, корзина, цвета плёнки (пиксели canvas, рендер капота), заказ, чек, Datenschutz без потери формы
node tests/desk.cjs     # боковая панель, десктоп 1920×1080, 1280×720, 1024×768, 1440×900, 2560×1080 + планшет 820×1180 + телефон в ландшафте + ресайз туда-обратно

node tests/layers3.cjs  # диагностика перерисовок слоёв
```
