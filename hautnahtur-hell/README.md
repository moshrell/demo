# hautnahtur-hell — сайт Hautnahtur, светлый вариант (A)

Просмотр: https://moshrell.github.io/demo/hautnahtur-hell/ . Копия `hautnahtur-kino/` (26.11.2026), отличается только героем и шрифтом. Данные клиентки те же, что в `hautnahtur/` (см. его README: что взято с её сайта и TODO к ней).

## Дизайн
- Весь сайт светлый, шапка белая. Шрифт один: Figtree (заголовки 650). Акценты из логотипа: ржавый `#B4482F` (кнопки), оранжевый `#E08A1E`.
- Герой: видео пасты (`public/video/`, рендер из `zuckerpaste/`) в скруглённом окне. Телефон стоя: окно сверху, высота подстраивается под экран (`clamp(11rem, 100svh - 33.5rem, 30rem)`), чтобы кнопка «Preis für meine Zonen» всегда была над панелью. Планшет стоя: то же, видео 16:9. ПК и телефон боком: текст слева, окно справа.
- Нижняя панель: белое матовое стекло, кнопка ржавая. Медовые текстуры убраны.

## Проверено
- pagecheck 360×640, 390×844, 820×1180, 844×390, 1440×900: чисто (кроме скрытой ссылки «Zum Inhalt»). Кнопка героя над панелью на 360×640, 375×667, 390×844, 412×915 (зазор 15–39 px).
- `tools/regress.mjs --audit`: оставшиеся находки — мутные фото (её старые маленькие файлы), кружок «к лицу» на фигуре на телефоне 21–36 px (есть кнопка «Gesicht»), панель боком «32 % экрана» (считается вся полоса, капсула 56 px справа), скрытый заголовок `.sr`.
- На настоящем iPhone не проверено.
