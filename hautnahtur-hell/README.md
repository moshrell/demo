# hautnahtur-hell — сайт Hautnahtur, вариант A «Preiskarte» (прейскурант)

Просмотр: https://moshrell.github.io/demo/hautnahtur-hell/ . Дизайн собран заново 26–27.11.2026 (не перекраска). Данные клиентки те же, что в `hautnahtur/` (там: что взято с её сайта и TODO к ней).

## Идея и дизайн
- Сайт как светлая прейскурантная карточка салона: фирменный элемент — строка «название ····· цена» с оранжевым пунктиром (`.karte-zeile`), повторяется в герое, услугах, прейскуранте, калькуляторе.
- Палитра: белый + песочный `#F5F1EC`, текст `#231812`, кнопки ржавые `#B4482F`, пунктир оранжевый `#E3861B` (оба из логотипа). Шрифт один: Figtree.
- Герой: видео пасты (`public/video/`, рендер `zuckerpaste/`) в скруглённом окне + три строки цен. Телефон стоя: окно сверху, высота подстраивается так, чтобы кнопка была над нижней панелью. Планшет стоя и ПК: две колонки. Телефон боком: окно справа.
- Главная: быстрый выбор 8 зон с живой суммой → полный калькулятор на `sugaring/`; услуги строками с фото-полосами; «Ich bin Michaela»; студия.
- Телефон: снизу панель «Anrufen / Termin anfragen». Планшет стоя и ПК: панели нет, меню и кнопка в шапке. Калькулятор на планшете и ПК: фигура слева, управление справа.
