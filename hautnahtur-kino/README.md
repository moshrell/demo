# hautnahtur-kino — вариант дизайна сайта Hautnahtur «как кино»

Копия `hautnahtur/` (24.11.2026) для пробы нового направления. Рабочая версия для клиентки остаётся в `hautnahtur/`.
Просмотр: https://moshrell.github.io/demo/hautnahtur-kino/ (пока тот же сайт, что hautnahtur).

## Направление (решение Степана)
- Продаёт дорогой контент: фоновые видео (Grok Imagine), отдельно для ПК 16:9 и телефона 9:16.
- Простые чёткие шрифты, минимум цвета, блоки не закрашивать сплошь.
- Калькулятор: реалистичная анатомическая фигура вместо плоской, осторожная подсветка выбранных зон.
- Цены Sugaring только «ab» (как в hautnahtur).

## Видео
Grok видео делать отказался, поэтому фон отрисован в Blender (папка `zuckerpaste/`, рендер на видеокарте Степана).
- `public/video/paste-pc.mp4` (1920×1080, 1,4 МБ) и `paste-tel.mp4` (720×1280, 0,7 МБ), петля 7,5 с без шва; `paste-*.jpg`: первый кадр (виден до старта видео, при reduced-motion и в энергосбережении iOS).
- Герой (`src/components/Held.astro`): телефон стоя: 9:16 в верхних 47 % экрана, текст ниже; планшет стоя: 16:9, кучка по центру справа; ПК и телефон боком: 16:9 на весь экран, текст слева на затемнении. Видео выбирается скриптом по ориентации, при повороте меняется.
- Проверено (скрины 360×640, 390×844, 820×1180, 844×390, 1440×900; pagecheck чистый): видео играет, кнопка «Preis für meine Zonen» над панелью, текст не уходит под панель. На настоящем iPhone не проверено.
