USER FLOWS
Семья (телефон): главная → видит готовый дом вечером и заголовок → листает: дом «откатывается» к пустому участку и строится по фазам, на каждой фазе срок и доля оплаты → после сцены «Was planen Sie?» → «Neubau» → Grundstücks-Check: вводит адрес → видит свой участок → ставит Einfamilienhaus → зона отступа зелёная → «Mit diesem Grundstück anfragen» → Anfrage со сводкой участка → бюджет, старт → имя/телефон → согласие → отправлено, видит, что будет дальше (звонок за 2 рабочих дня, затем встреча на участке).
Архитектор (ПК): главная → меню «Für Architekten» → мощности, регионы, типы, контакт Polier, «LV senden» (форма с файлом) → или Referenzen с фильтром «Gewerbe».
Старый дом (телефон): главная → «Anbau / Aufstockung» → Leistungen-секция: что нужно, сроки, «ab»-цена → «Passt das auf mein Grundstück?» → Grundstücks-Check с типом «Anbau 6×8» → или сразу «Anrufen».
Быстрый: любой экран → нижняя панель «Anrufen» / «Anfrage».
Соискатель: футер/меню «Karriere» → вакансии с вилкой → Bewerbung (имя, телефон, профессия) → отправлено.

МЕХАНИКА
Главная: закреплённая сцена 7 кадров одного дома 3:4. Первый экран = вечерний готовый дом (обещание) с заголовком. Прокрутка: кадр «откатывается» на пустой участок (фаза 0), дальше каждая фаза вырастает маской снизу вверх (на крыше — по скату), камера чуть дышит (scale), выноски-линии подписывают новое. Панель фазы: номер, название, что делаем, недели, % оплаты; полоса оплаты растёт. Точки фаз — тап = прыжок. «Überspringen» ведёт к «Was planen Sie?».
Телефон: кадр на всю ширину сверху (около 62 % высоты экрана), панель снизу; ПК: кадр слева в колонке, панель справа крупно.
1-я секунда: вечерний дом + заголовок по словам + две кнопки. 3-я: начал листать — дом исчезает до пустого участка, «Phase 0 · Grundstück». 10-я: стены + «20 % nach Rohbau EG».
Grundstücks-Check: адрес → участок LGLN → правка вершин → тип дома → перетаскивание/поворот → отступ 3 м зелёный/красный → GRZ → заявка.

FALLBACK
reduced-motion: фазы списком, без pin; без JS: список + формы работают; нет сети/вне Niedersachsen: ручной ввод размеров; нет картинок: аккуратные заглушки только в разработке.
