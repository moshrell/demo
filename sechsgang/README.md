# Sechsgang

Astro-Projekt (Demo, Fahrzeugdienste: Überführung, Fahrzeugsuche, Charter, Papiere). Адрес на портфолио: `/vorschau/auto/sechsgang/`

    START.bat           # первый запуск ставит пакеты, дальше dev-сервер
    npm run build       # сборка + плашка ИИ + dist/.htaccess (CSP с хэшами, noindex)
    npm run publish     # сборка + копия в ..\kravets-site\public\vorschau\auto\sechsgang

## Идея
Навигация = рычаг КПП. Внизу (на телефоне под большим пальцем, на ПК справа в «консоли») H-кулиса с 8 позициями:
R (Rückruf, форма), N (Leerlauf, старт), 1 Überführung, 2 Fahrzeugsuche, 3 Charter, 4 Papiere, 5 Preise (калькулятор), 6 Über uns.
Рычаг тянется пальцем/мышью строго по кулисе (по горизонтали только в нейтральной линии, по вертикали только в «улочках»).
Страница меняется в момент, когда рычаг входит в позицию (щелчок: вибрация на Android; звука нет). При каждой загрузке на N рычаг сам «дёргается» (кольцо + ход в колонку 1/2 и назад), пока пользователь не воспользуется им. При чтении (скролл вниз) док на телефоне сворачивается в узкую полосу с кнопкой «Schalten».
Отпустил в нейтрали по центру = N. Отпустил где-то ещё = рычаг пружиной возвращается в текущую передачу.
Страницы лежат на горизонтальной ленте; дорожная разметка и полоска оборотов в шапке двигаются вместе с ней.
Заголовки «ускоряются»: ширина шрифта Anybody растёт с номером передачи (1 = узкий, 6 = широкий).

Альтернативы перетаскиванию (доступность): карточки на старте, кнопка «Alle Gänge» (список вкладок), клавиатура на рычаге
(← → смена передачи, ↑ ↓ внутри улочки, Esc = N), адрес `#1`…`#6`, `#r`, `#n` + кнопка «Назад» браузера.
Без JS все 8 передач идут друг под другом, сверху ссылки-якоря.

## Что взято и что нет (вдохновение: идея b2plusk.de)
Взята только механика интерфейса (идея «переключать страницы рычагом КПП») и тема «Fahrzeugdienste». Код, тексты, дизайн, бренд, фото,
структура разделов, цены и названия свои. Ничего не скопировано. Реальная фирма не упоминается на сайте.

## Каноны (проверено тестами, Playwright, 360–1920 px)
- Mobile first: CSS от телефона, `min-width` 640 / 900 / 1200. Рычаг ≥ 46 px, все кнопки ≥ 44 px, нет горизонтального скролла.
- Форма по стандарту (`CallbackForm.astro` = OrderForm + группы выбора + блок из калькулятора): placeholder'ы «z. B. …», согласие со ссылкой на Datenschutz (новая вкладка),
  введённое не теряется (sessionStorage `form:/…:rueckruf`, калькулятор `sg-calc-v1`), переживает смену передач, reload и переход на Datenschutz.
- Бегущая сумма: в калькуляторе (липкая плашка), в форме (липкая плашка), в подтверждении. Пока калькулятор не тронут, сумму не придумываем.
- Клавиатура на телефоне: пока вводишь текст, кулиса скрывается, чтобы не съедать экран.
- reduced-motion: без анимаций, мгновенное переключение.
