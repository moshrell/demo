# Demo: Elektro Brakhage («Stromkreis»)

Статус: **сайт собран (Astro) с фото из Gemini, проверен headless на 320–1280 px; ждёт ревью Степана на телефоне.**
Живая версия после push: https://moshrell.github.io/demo/stromkreis/ · Разведка: `RECON.txt` · ТЗ владельца: `TZ.txt` · Промпты: `PROMPTS.txt`.
Фирма вымышленная: Elektro Brakhage, Gehrden (имя «Hellwig» из брифа заменено: в Nordhorn есть реальная «Hellwig Elektrotechnik»). Адрес, телефоны (Drama Numbers 030 23125), HWK-номер и USt-ID — выдуманы.

## Механика
Главная = хаб без длинного скролла: тёмный Sicherungskasten (щиток) → Hauptschalter (главный рубильник) → разрез дома ночью → автоматы внизу включают комнаты → карточка услуги → тап по светлой комнате = наезд камеры (фиксированная точка) → страница услуги. «Alles an», «Licht aus», «Ohne Licht direkt zu den Leistungen» и Schnellzugriff (быстрый список с ценами) всегда доступны. Нижняя панель (Anrufen / Notdienst / Anfrage) на всех страницах. Статус «открыто/закрыто» по Europe/Berlin.
Состояние дома, ответы инструментов и PLZ — в sessionStorage. Нет WebGL вообще: фото + HTML.

Инструменты: Wallbox-Check (`/wallbox/`, 5 вопросов, бегущая сумма) · E-Check-Rechner (`/e-check/`, netto + MwSt. + brutto) · «Ist meine Elektrik alt?» (`/altbau/`) · PLZ-проверка района с ценой Anfahrt (выезда). Все ведут в `AnfrageForm.astro` и переносят сводку и сумму.

## 3D-срез (новое направление главной, на ревью)
`/slice/` (не в меню): живая 3D-сцена вместо щитка. Дом в разрезе ночью, скролл зажигает комнаты по очереди, тап по комнате = камера летит к якорной точке (Küche: плита, Garage: Wallbox, Bad: ванна), «Zurück» возвращает. Код: `src/scripts/haus3d.ts` + `src/pages/slice.astro`. Модели: Kenney Furniture Kit и Car Kit (CC0, лицензии в `public/3d/`), оболочка дома собрана из боксов. Нет внешних запросов. Искры под пальцем (только тач, выкл. при reduced-motion), без WebGL показывается сообщение.
Не решено: интерьеры блочные (Kenney), композиция кадров в комнатах средняя; сцена не оптимизирована (≈260 draw calls, 11k треугольников, JS ≈600 КБ без сжатия): объединить статичную геометрию; реальный fps на телефоне не измерен (проверка только в headless с программным рендером); главная `/` пока старая (щиток), решение после ревью срезa.

- Токены: `src/styles/tokens.css` (hallmark: кастом-тема, графит + янтарь 2700K + кремовые полоски; Sofia Sans Condensed / Sofia Sans / Martian Mono, локально).

## Фото
16 кадров из `PROMPTS.txt` подключены как WebP в `public/img/` (оригиналы jpg лежат только у Степана в `D:\Webdesign\stromkreis\public\img\`, в git не идут: `.gitignore`). Если файла нет, на его месте полосатая плашка «Foto folgt», дом рисуется схемой.
Кадры `haus-dunkel` / `haus-hell` совпали пиксель в пиксель (сдвиг 0). Контуры комнат взяты из разницы двух кадров скриптом `tools/masken.py` (python3, Pillow, scipy; запуск: `python3 tools/masken.py public/img`, нужны jpg-оригиналы или переименовать вход), результат вручную перенесён в `src/data/haus.json` (`poly` = область света, `hit` = область тапа, `lamp` = точка лампы, `pin` = булавка Referenz). Рейки щитка в `haus.json → rails` (31,3 / 50,9 / 70,3 % высоты кадра, ширина рейки 26–74 %). Если кадры перегенерируются, пересчитать полигоны и рейки.

## Известные недочёты
- Лампы «Keller» и «Garten» в `haus.json` заданы вручную (в подвале две лампы, в саду три столбика), остальные найдены по максимуму прироста яркости.
- Не проверено глазами: вёрстка хаба на разных высотах телефона, плавность анимаций на реальном iPhone/Android. Глазами смотрел только исходные кадры Gemini (раскладка комнат и фото щитка), сайт целиком — нет. Наклон по гироскопу работает только там, где не нужно разрешение (Android); на iOS остаётся drag.
- Цены демонстрационные: ориентир по открытым данным (ADAC: Wallbox 500–3 000 € монтаж; прайсы DGUV V3 3–8,50 € за прибор + выезд). На живом клиенте заменить своими. Нулевая ставка MwSt. для PV (до 30 kWp) указана по публикации priwatt.de; относится ли к ней Zählerschrank, в тексте оставлено «клиентом уточняется».
- Формы ничего не отправляют (демо). Фото в форме — только превью в браузере. В реальном проекте отправка идёт через PHP на All-Inkl (фото как вложение), Datenschutz подправить.
- Телефон/e-mail/Handwerksrolle/USt-ID/Berufshaftpflicht в Impressum: вымышленные или `TODO vom Kunden`.

## Технически
`npm run build` (astro build + ki-hinweis + htaccess/CSP с хэшами). Все ссылки через `import.meta.env.BASE_URL`. Без внешних запросов.
Проверено (headless, без скриншотов): нет горизонтального скролла и обрезанного контента на 320/375/390/414/768/1280, нет ошибок консоли и битых запросов, нет двустрочных кликабельных текстов, все внутренние ссылки 200, reduced-motion и отключённый JS (дом сразу светится, ссылки работают), форма не теряет данные (Datenschutz в новой вкладке, перезагрузка), согласие не восстанавливается.
