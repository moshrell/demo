# Studio Kamm v2 — демо №2 (парикмахерская), структура «сайт = запись»

Не лендинг, а приложение записи. Слева фото-витрина, которая меняется вслед за выбором
(категория → её фото, мастер → его портрет), статус «открыто», отзывы. Справа шаги:
Leistung → Stylist → Termin → Daten → билет с кнопкой «в календарь» (.ics).
Цены, работы, команда и контакты — в выезжающих панелях (на телефоне — снизу).
Кнопка «назад» в браузере/телефоне возвращает на шаг назад.

Фото: src/assets/photos/ (имена — в src/data/site.json). Пока файла нет, показывается заглушка с именем.

    npm install
    npm run dev        # http://localhost:4321/vorschau/friseur/studio-kamm/
    npm run publish    # сборка + копия в ..\kravets-site\public\vorschau\friseur\studio-kamm
