# uhren — демо вымышленного часового бренда (старт 15.11.2026)

Цель: сайт, который выглядит максимально дорого. В центре — собственный часовой калибр,
целиком построенный кодом в Blender (без скачанных моделей). Позже: скролл-разбор механизма,
3D в реальном времени поверх фотореальных рендеров. Ниша вторична, это витрина возможностей.

Рабочее имя бренда: **Calenberg**, калибр **C 01** (по Calenberger Land — местность вокруг Гердена/Ганновера).
Имя выбрал Claude как рабочее; меняется одной константой `BRAND` в `build.py` (гравировка перестроится сама).

## Что лежит
- `build.py` — вся сцена (bpy + shapely), единицы = миллиметры, диаметр механизма 30,6 мм.
- `calenberg_c01.blend` — готовая сцена: 125 мешей, 5 камер (`cam_hero`, `cam_top`, `cam_macro_*`),
  у каждой камеры свой комплект софтбоксов (коллекции `rig_*`).
- `renders/` — финальные кадры: `hero.png` (общий план, 2400×3000), `top.png` (вид сверху, 3000×3000),
  `macro_balance.png`, `macro_train.png`, `macro_winding.png` (крупные планы, 3000×2000).
  `hero_v2.png` — старый тест из облака, оставлен для сравнения.

## Запуск
Blender 5.0.1 лежит в `D:\Webdesign\tools\blender`, shapely уже установлен в его Python.

```
D:\Webdesign\tools\blender\blender.exe -b -P build.py -- <папка_вывода> <сэмплы> <камеры через запятую> <масштаб %> [--save] [--norender]
```
- Превью: `... -- renders_test 64 hero,top 40` (~20 с на кадр).
- Финал: `... -- renders 300 hero,top,macro_balance,macro_train,macro_winding 100 --save`.
- Рендер: Cycles, OptiX на GTX 1650, адаптивные сэмплы + денойз, AgX.
- Blender 5: у новых материалов нет узлов по умолчанию, скрипт создаёт их сам (`new_mat`).

## Работа из облака (репозиторий `moshrell/demo`, папка `uhren/`)
- В репозитории лежит всё: `build.py`, `calenberg_c01.blend`, `renders/`, этот README. Не лежит только `*.blend1`
  (автокопия Blender) и тестовые папки `renders_test/` — они в `.gitignore`.
- Blender в облаке ставится заново (Linux-сборка 5.0.1 с download.blender.org, распаковать вне репозитория),
  затем shapely в его Python: `<blender>/5.0/python/bin/python3* -m pip install shapely`.
- Запуск тот же: `<blender>/blender -b -P build.py -- <папка> <сэмплы> <камеры> <масштаб %> [--save] [--norender]`.
- Видеокарты в облаке нет: OptiX не найдётся, рендер пойдёт на CPU (медленнее). Превью гонять с малым масштабом
  и 32–64 сэмплами; финальные кадры в полном размере лучше считать на ПК Степана (GTX 1650).
- На ПК Степана изменения из облака появляются только после того, как он заберёт их из GitHub в `D:\Webdesign\uhren`.

## Характер
Двухцветный калибр с ручным заводом: светлые мосты тёплого родиевого тона с женевскими полосами
«парят» над тёмной антрацитовой платиной с перлажем; колёса и шатоны из розового золота,
синёные винты и спираль, стальные детали зеркальной полировки, гравировки залиты розовым золотом.

## Что готово
- **Компоновка (собственная):** барабан → центральное → третье → четвёртое (секундное) → анкерное колесо →
  анкерная вилка с рубиновыми палетами → баланс. Колёса реально стоят на межосевых расстояниях зацепления.
- **Мосты (6 шт.):** мост барабана, мост колёсной передачи, пальцевой мост четвёртого колеса,
  низкий мост анкерного колеса, мост вилки, балансовый мост. У всех опоры до платины, широкая полированная
  фаска (anglage) 0,16 мм, сатинированные торцы, острые внутренние углы.
- **Отделка:** женевские полосы (анизотропия с веером направления штриха по дуге, единая сетка на всех мостах),
  перлаж перекрывающимися кругами со сдвигом рядов (крупный на платине, мелкий в расточках),
  лучевая шлифовка заводных колёс, круговая на золотых колёсах и балансе.
- **Платина:** ступенчатый край, расточки (карманы) под колёса и баланс, ограничительные штифты вилки.
- **Завод:** храповое и заводное колёса (волчий зуб), собачка с пружиной, заводной вал.
- **Баланс:** обод с 16 золотыми винтами, спираль с концевой кривой, колодка, ролик с импульсным камнем,
  накладка с накладным камнем, регулятор «лебединая шея» с микрометрическим винтом.
- **Камни:** рубины в золотых шатонах, центральный шатон привинчен тремя синёными винтами.
- **Винты:** выпуклая полированная головка, фаска, шлиц (вырезан булевой операцией, дно шлица матовое).
- **Гравировки (врезаны + заливка):** `CALENBERG`, `HANNOVER · KALIBER C 01` по дуге,
  `IN FÜNF LAGEN REGULIERT` («отрегулировано в пяти положениях»), `21 STEINE` («21 камень»).
- **Местный мотив:** на балансовом мосту врезан силуэт Neues Rathaus Hannover (Новая ратуша: купол с фонарём,
  крылья, угловые башенки) с заливкой розовым золотом — объект `engraving_rathaus`, функция `rathaus()`.
  Силуэт стилизованный (1,5 мм шириной), не точная копия фасада.
- **Свет и сцена:** студийные софтбоксы с градиентом, поворачиваются под азимут каждой камеры;
  чёрная глянцевая подложка с отражением; малая глубина резкости.

## Имена объектов (для скролл-анимации)
Каждая деталь — отдельный меш: `mainplate`, `barrel_bridge`, `train_bridge`, `fourth_wheel_cock`,
`escape_wheel_cock`, `pallet_bridge`, `balance_cock`, `barrel`, `centre_wheel`, `third_wheel`, `fourth_wheel`,
`escape_wheel`, `pallet_fork`, `pallet_stone_1/2`, `balance_wheel`, `balance_screw_01…16`, `hairspring`,
`ratchet_wheel`, `crown_wheel`, `click`, `click_spring`, `regulator`, `swan_neck_spring`, `screw_*`,
`jewel_*_chaton` / `jewel_*_ruby`, `*_arbor`, `*_pinion`, `winding_stem`.
Гравировки (`engraving_*`) — дочерние объекты своих мостов, двигаются вместе с ними.
Важно: у мостов и платины origin в центре механизма (0,0) — на этом держится непрерывность полос и перлажа.
Двигать можно свободно; origin не переносить (или переносить вместе с текстурными координатами).
Колёса, винты и камни имеют origin на своей оси — их можно сразу вращать.

## Известные недостатки (доделать)
- **Стык опоры и плиты моста виден:** на опорах мостов горизонтальная линия-канавка, а у пальцевого моста
  четвёртого колеса на крупном плане (`macro_train.png`) — зарубка на фаске там, где опора выходит из-под плиты.
  Лечится построением моста одним мешем (плита + опора через union до экструзии), а не двумя пересекающимися.
- Число камней на гравировке (21) условное: в модели видимых камней меньше, нижние не моделировались.
- Импульсный камень не доходит до рожек вилки по высоте; под мостами нет деталей ремонтуара
  (с обратной стороны механизм не проработан, циферблатной стороны нет).
- Зубья колёс — трапеции, не циклоидальный профиль; трибы упрощённые. В макро на резкости это видно знатоку.
- Спираль — плоская, без брегетовской концевой кривой; штифтов градусника под мостом нет.
- Гнёзда винтов — простая фаска отверстия, без отдельной полированной зенковки.
- Рубины с небольшой подсветкой (emission 0,07), иначе в тёмном окружении чернеют — это приём, не физика.
- На полированных деталях есть лёгкая неровность блеска, но пыли, микроцарапин и дефектов объектива нет:
  кадр всё ещё чище настоящей съёмки. Плёночное зерно и лёгкую виньетку лучше добавить на посте.
- Общий план: передний край платины и подложка уходят в почти чёрное; для светлого дизайна сайта
  понадобится отдельный вариант света/фона.
- Спираль на общем плане читается тонкими линиями (муар при уменьшении возможен).
- Для веба меши тяжёлые (полигоны от кривых): перед экспортом в glTF нужна ретопология/упрощение
  и запекание процедурных материалов в текстуры.

## Правила
- Калибр собственный, не копия реального бренда. Название бренда вымышленное.
- Все детали — отдельные объекты с понятными именами (будут двигаться в скролл-анимации).
- Финальные кадры класть в `renders/`, этот README обновлять на месте.

## Идеи на потом
- **Циферблат с местным мотивом:** циферблатной стороны пока нет. Когда появится — фоном гильоше/рельеф
  с силуэтом Neues Rathaus или Marktkirche (Рыночная церковь). Маленькая версия уже есть гравировкой на балансовом мосту.

## Технические заметки (грабли)
- Булевы операции: резать только чистую плиту моста ДО присоединения опор (`bridge(..., engr=[...])`),
  иначе EXACT выворачивает меш.
- Острые выпуклые углы контура дают шипы на фаске кривой — `shape_obj` их скругляет на 0,04 мм.
- Отверстия ближе фаски друг к другу сливаются и ломают заливку (так появились «иглы» через кадр).
