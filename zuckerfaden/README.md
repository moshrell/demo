# zuckerfaden — демо косметического кабинета «Kosmetik Zuckerfaden» (вымышленный, Ronnenberg)

Просмотр: https://moshrell.github.io/demo/zuckerfaden/ · ТЗ: `_briefs/kosmetik/01_kosmetik_zuckerfaden.txt` · Фото: `PROMPTS.txt`
Портфолио: `/vorschau/kosmetik/zuckerfaden/` (категорию `kosmetik` проверить в kravets-site works.ts перед публикацией).

## Статус (19.11.2026, версия 3.1 после внешнего ревью)
Все страницы по ТЗ. Тёмная сцена + светлые блоки; мёд только там, где деньги и запись (зоны, сумма, кнопки, панель); карточки-советы светлые с медовой линией. Фото героя не нужны: на телефоне герой без фото, на ПК арка с банкой пасты (`pflege-1x1`).

## Как устроено
- `src/data/*.json` — тексты, цены, часы, зоны, процедуры, пары шрифтов. Переход на реального клиента = замена JSON (см. ТЗ).
- Мёд — **заранее отрисованные** текстуры `public/img/honig-leiste|band|tropfen.webp`, их делает `tools/honig-textur.mjs` (WebGL-шейдер `src/scripts/honig-gl.ts` в headless Chrome; запуск `node tools/honig-textur.mjs`, затем PNG→WebP). В браузере WebGL нет (раньше два контекста, подозрение на падение сайта на телефоне).
- Нижняя панель/пилюля/шапка ПК: капсула через `border-image` с текстурой; на ПК панель скрыта, меню сверху (липкая шапка), внизу остаётся только пилюля выбора.
- `src/scripts/honig.ts` — одна SVG-нить мёда между блоками, обновляется только при прокрутке, только на телефоне.
- Фигуры: `src/lib/koerper.mjs` + `koerper.json` — готовые силуэты из `@mjcdev/react-body-highlighter` (MIT, лицензия `LICENSE-koerper.txt`); зоны — их части, подписи через getScreenCTM; кушетка под фигурой; при первом показе зоны один раз по очереди подсвечиваются (подсказка, куда нажимать); голова на виде спереди открывает вкладку лица.
- Лицо Damen/Herren: `src/lib/gesicht.mjs` (линейный рисунок, зоны с пунктиром в покое). У мужчин зоны лица: Augenbrauen 12 €, Nase/Ohren 9 €, Bartkontur 12 €, Hals/Nacken 14 € — цены придуманы для демо, у реального клиента сверить. `src/lib/figur.mjs` нужен только как `smooth()`.
- Шрифты: Gilda Display (заголовки) + Manrope (текст), локально через @fontsource. Переключатель шрифтов убран (Степан выбрал вариант B).
- Шапка ПК: тонкая тёмная полоса, текстовое меню с медовой чертой у активного пункта, маленькая медовая кнопка «Termin anfragen». Медовая капсула только у нижней панели телефона и пилюли.
- Подписи цен у фигуры: высота меряется, подписи не наезжают друг на друга; больше трёх с одной стороны — компактная строка. Зоны нажатия шире самих зон (46, руки 72 единицы).
- Телефон боком: калькулятор в две колонки, фигура целиком над нижней панелью.
- Пилюля суммы прячется, пока на экране свой итог (`[data-pille-weg]`: карточка калькулятора, сводка в форме записи). Подсказка «Beine komplett ist günstiger» (= «Ноги целиком дешевле») — в карточке итога, на телефоне ещё строкой под фигурой, плюс в шторке «Ihre Auswahl».
- Капли в герое падают два раза и замирают (ТЗ: спокойный сайт).
- Нижняя панель компактная (56 px, макс. 23rem, колонки сжимаются), не вылезает за край даже при 360 px и крупном системном шрифте. `.btn` переносит текст (раньше nowrap раздвигал страницу на узких экранах).
- `src/components/Finder.astro` — мастер «Welche Gesichtsbehandlung passt zu mir?» (Welche… passt zu mir = «Какая процедура для лица мне подходит»): по одному вопросу, прогресс-нить, результат с карточкой.
- `src/pages/termin.astro` — подтверждение: медовая печать с галочкой, имя, сводка, 3 шага «что дальше».
- `src/lib/cart.ts`, `src/scripts/ui.ts`, `scripts/bilder.mjs`, `lib/formular.ts` — как раньше (корзина, шторки, часы, WebP, формы по правилам).

## Проверено (числами, headless Chrome)
- pagecheck на 390×844, 360×740, 768×1024, 844×390, 1440×900 для всех страниц: нет горизонтальной прокрутки, нет ошибок консоли, после перезагрузки страница сверху. Предупреждения только ожидаемые: skip-ссылка за краем, горизонтальная лента якорей на Preise, `.sr`-заголовок.
- Сценарии: зоны касанием → Summe/Dauer, подсказка Beine komplett и её принятие, панель лица, «inklusive» при процедуре лица, подбор процедуры, пилюля; Termin: ошибки, сохранение после перезагрузки, Abend блокируется без Di/Do, карточка подтверждения; Gutschein: свой Betrag; смена шрифта сохраняется между страницами.
- Скриншотами посмотрены: герой (телефон/ПК), калькулятор Damen/Herren спереди, лицо Damen/Herren, подсказка комбинации, скрытие пилюли, мастер подбора, меню со шрифтами, подтверждение записи, первые экраны Sugaring, Gesicht, Preise, Gutschein, Über mich, Termin.
- Контраст: kandis на медовых блоках ≥ 5:1 (градиент до `--honig-tief`), вторичный текст 6.3:1, placeholder 4.7:1.

## Проверка крупного шрифта
- Эмуляция крупного системного шрифта Android (html 118–130 %) на 360/412 px: ничего не выходит за край (кроме декоративных капель внутри обрезанного слоя), карточки подбора и футер переносятся.

- Кнопка «Bewertungen auf Google» в демо неактивна с пометкой (TODO: профиль клиента).
