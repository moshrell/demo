# zuckerpaste — фоновое видео «сахарная паста» для hautnahtur-kino

Густая янтарная паста стекает со шпателя и укладывается кольцами в лужицу на тёмном камне. Всё построено кодом в Blender 5.0.1 (`coil.py`), без симуляции:
нить и кольца из metaball-элементов, их положение считается формулой на каждый кадр. Поэтому петля бесшовная: 180 кадров = 6 колец по 30 кадров, кадр 181 совпадает с кадром 1.

## Запуск
- ПК Степана (GTX 1650): `run.bat` в этой папке. Пишет `frames_pc/` (1920×1080) и `frames_tel/` (1080×1920), логи `log_pc.txt`, `log_tel.txt`, в конце `fertig.txt`. Готовые кадры пропускаются.
- Вручную: `blender -b --factory-startup -P coil.py -- <папка> <ширина> <высота> <сэмплы> <all|a-b|a,b> <cam_pc|cam_tel>`.
- Облако: тот же Blender для Linux, CPU, превью 640×360 / 24 сэмпла ~10 с на кадр.

## Кадр
- `cam_pc`: кучка справа, слева тьма под текст. `cam_tel`: нить сверху, кучка в нижней трети.
- Камеры неподвижны (иначе петля не замкнётся). Свет: контровой сверху-сзади (`back`, spread 35°), блик сбоку, слабый фронт.
- Пол — почти чёрный диффуз с 6 % глянца: сильный глянец давал белое отражение контрового света.

## Пробовали и отказались
- Симуляция Mantaflow (вязкая жидкость): в облаке 2 ядра, струя выходила прямым «стеклянным прутом» без колец, петлю не замкнуть. `bake_all` в фоне ничего не пишет, работает только пошаговый REPLAY-кэш.
