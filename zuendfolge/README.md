# Zündfolge

Astro-Projekt (Demo, Kfz-Werkstatt). Адрес на портфолио: `/vorschau/auto/zuendfolge/`

    START.bat           # первый запуск ставит пакеты, дальше dev-сервер
    npm run build       # сборка + плашка ИИ + dist/.htaccess (CSP с хэшами, noindex)
    npm run publish     # сборка + копия в ..\kravets-site\public\vorschau\auto\zuendfolge

## Идея
Сайт как приборная панель. Hero: приборка делает «Selbsttest» (самотест) при старте: лампы вспыхивают,
стрелки качаются до упора и возвращаются, цилиндры логотипа зажигаются в порядке 1-3-4-2 (Zündfolge).
Дальше «Bordcomputer» (бортовой компьютер): 5 разделов (Warnleuchten, Geräusche, Fahrgefühl, Fällig,
Unfall und Lack), 29 симптомов. Каждый даёт «Befund» (заключение): светофор срочности (weiterfahren /
bald prüfen / nicht weiterfahren / planbar), что значит, что делаем, время, цена «ab». Кнопка ведёт в форму с уже
выбранным Anliegen (причиной обращения).

Дальше: HU-Plakette (наклейка техосмотра) как калькулятор. Цвет по году (цикл blau, gelb, braun, rosa,
grün, orange; 2026 = blau), цифры вращаются так, что месяц оказывается наверху, как на настоящей наклейке.
Считает, сколько осталось, и штрафы при просрочке (до 2 мес. без штрафа, затем 15 / 25 / 60 € + 1 балл).
«Prüfprotokoll» (протокол проверки) вместо блока «почему мы». «Tankanzeige» (указатель топлива) =
остаток рабочего дня по берлинскому времени. Форма даёт «Auftragszettel» (заказ-наряд), ничего не отправляет.

## Данные
Всё в `src/data/site.json`: симптомы, цены, часы работы, адрес. Правки там, не в разметке.

- Все цены «ab», длительность работ, «Meisterbetrieb», Hol- und Bringservice 10 км, Ersatzwagen, часы работы.
- Impressum/Datenschutz: полноценный шаблон, все данные клиента = `TODO vom Kunden` (имя, адрес, Handwerkskammer, USt-IdNr., хостер/AVV, срок хранения, проверка адреса LfD Niedersachsen). Перед боем проверить юристом.

## Каноны (проверено тестами)
- Mobile first: CSS от телефона, `min-width` 640/900/1100. Лампы в первом экране на 360×740, 375×667, 390×844. Панель «Позвонить» всегда внизу на телефоне, кнопки ≥44px.
- Befund (диагноз): на телефоне bottom-sheet через `<dialog>`, на ПК карточка рядом со списком, без JS всё открыто.
- Бегущий итог: «Auftrag» с ценой «ab X €», дублируется в кнопке панели и карточке.
- Форма: placeholder'ы «z. B. …», чекбокс согласия со ссылкой на Datenschutz (новая вкладка), без Kennzeichen (спрашиваем по телефону).
- Введённые данные не теряются: `sessionStorage` (`zf-draft-v1`), переживают переход на Datenschutz/Impressum и reload, очищаются после отправки.
